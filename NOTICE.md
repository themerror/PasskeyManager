# Attributions

This project is a C# implementation informed by Microsoft's official samples:

- [Windows-classic-samples / PasskeyManager](https://github.com/microsoft/Windows-classic-samples/tree/main/Samples/PasskeyManager), including the plugin flow, native API contracts, and authenticator-data structure.
- [.NET Samples / Out-of-process COM Server](https://github.com/dotnet/samples/tree/main/core/extensions/OutOfProcCOM), including the managed class-factory registration pattern.
- [microsoft/webauthn](https://github.com/microsoft/webauthn), including the official WebAuthn headers and structure versions.

The application also uses the Windows App SDK C# WinUI project template and its placeholder image assets.
